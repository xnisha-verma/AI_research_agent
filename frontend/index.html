How it works

Web Scraping, Simplified

Our agent collects, processes, and analyzes public data — so you don't have to.

01

Scrape

Fetches top posts from Reddit, HN & Product Hunt RSS feeds using rate-limited HTTP requests.

~30 posts per platform
02

Store

Saves posts to PostgreSQL with deduplication. Auto-prunes data older than 3 days to respect free-tier limits.

500MB Supabase
03

Analyze

Sends post data to an LLM (Groq) to extract trending topics, categories, and sentiment scores.

Groq API / Fallback
04

Visualize

Trends are ranked by score and displayed in a real-time dashboard. Historical data persists across sessions.

Persistent Dashboard
